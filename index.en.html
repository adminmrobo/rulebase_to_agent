From the rule base of a flowchart
to AI that works

This series follows, in fifteen chapters, how the flowchart where people wrote IF-THEN rules became an LLM reasoning model (Part 1), and how that model came to hold tools and work on its own as an AI (Part 2). Each chapter includes formulas, hands-on diagrams, Python code that was actually run, and review questions.

Text · Ahn Sangsun (CEO, M-Robo Inc.)
