02

뉴런을 흉내 낸 퍼셉트론

뇌의 신경세포(뉴런)는 여러 가지돌기로 신호를 받아, 합이 일정 수준을 넘으면 축삭을 따라 다음 세포로 신호를 보냅니다. 1943년 매컬러와 피츠가 이를 수학 모형으로 옮겼고, 1958년 프랭크 로젠블랫이 데이터로 가중치를 학습하는 퍼셉트론을 만들었습니다.

ŷ = step( w1x1 + w2x2 + ⋯ + b )   ·   w ← w + η(y − ŷ)x
2장의 로지스틱 회귀와 똑같은 모양입니다. 시그모이드 대신 계단 함수를 썼을 뿐, 퍼셉트론 하나는 결국 "직선 하나"를 긋는 기계입니다.
03

직선 하나로는 안 되는 문제: XOR

XOR은 "둘 중 하나만 켜졌을 때만 1"인 규칙입니다. 네 점 중 대각선 두 점(초록 원)이 1, 나머지 두 점(주황 네모)이 0입니다. 슬라이더로 직선을 아무리 돌리고 옮겨도 네 점을 모두 가를 수 없습니다. 직접 해 보세요.

04

층을 쌓고 거꾸로 고친다: 역전파

층을 쌓으면 표현력은 커지지만 새 문제가 생깁니다. 출력이 틀렸을 때, 중간층 뉴런의 가중치는 각각 얼마나 책임이 있을까요? 1986년 루멜하트, 힌턴, 윌리엄스는 출력층의 오차를 거꾸로 한 층씩 전달하며 책임을 나누는 역전파(backpropagation)를 정리해 널리 알렸습니다. 강의 연표의 "1986 Backpropagation, Multilayer Network"가 바로 이것입니다.

∂L/∂w1 = ∂L/∂ŷ · ∂ŷ/∂h · ∂h/∂w1
연쇄법칙. 출력의 오차가 "출력 → 은닉층 → 입력 가중치" 순서로 곱해지며 거꾸로 흘러갑니다. 고치는 방법은 2장과 같습니다. w ← w − η · ∂L/∂w출처: Rumelhart, Hinton & Williams(1986) · 안상선(2021), 1강 연표
05

기계가 스스로 만든 특징

그럼 층이 깊어지면 무엇을 배울까요? 8×8 픽셀 손글씨 숫자 1,797장을 은닉 뉴런 16개짜리 신경망에 학습시킨 뒤, 첫 층 뉴런 8개의 가중치를 그림으로 그려 봤습니다. 아무도 "가로획을 찾아라", "동그라미를 찾아라"라고 알려 주지 않았습니다.

머신 비유. 3장의 기계는 보는 법을 배우는 기계입니다. 저울(2장)은 사람이 올려 준 것만 쟀지만, 이 기계는 사진을 통째로 받아 어디를 봐야 할지부터 스스로 정합니다. 사람은 몇 층으로 쌓을지 같은 구조를 설계하고, 정답 이름표를 붙여 줍니다.
06

파이썬 실험 노트

numpy와 scikit-learn만 씁니다. 손글씨 숫자 데이터는 scikit-learn에 들어 있어 내려받을 필요가 없습니다.

예제 1. 퍼셉트론 하나로 AND와 XOR 배우기

perceptron.py직선 하나의 한계
import numpy as np
X4 = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)

def perceptron(X, y, epochs=50, eta=0.1):
    w, b = np.zeros(2), 0.0
    for _ in range(epochs):
        for xi, yi in zip(X, y):
            y_hat = 1 if xi @ w + b > 0 else 0
            w += eta * (yi - y_hat) * xi          # η(y − ŷ)x : 2장의 그 식
            b += eta * (yi - y_hat)
    return [1 if xi @ w + b > 0 else 0 for xi in X]

for name, y in [("AND", [0, 0, 0, 1]), ("XOR", [0, 1, 1, 0])]:
    pred = perceptron(X4, np.array(y))
    print(f"{name}: 정답 {y} / 예측 {pred} → {sum(p == t for p, t in zip(pred, y))}/4 맞음")
실행 결과
AND: 정답 [0, 0, 0, 1] / 예측 [0, 0, 0, 1] → 4/4 맞음
XOR: 정답 [0, 1, 1, 0] / 예측 [1, 1, 0, 0] → 2/4 맞음

예제 2. 은닉층을 넣고 역전파로 XOR 풀기

backprop_xor.py입력 2 → 은닉 2 → 출력 1
rng = np.random.default_rng(0)
y = np.array([[0], [1], [1], [0]], dtype=float)
W1, b1 = rng.normal(0, 1, (2, 2)), np.zeros(2)
W2, b2 = rng.normal(0, 1, (2, 1)), np.zeros(1)
sig = lambda z: 1 / (1 + np.exp(-z))
eta = 1.0

for epoch in range(1, 5001):
    h = sig(X4 @ W1 + b1)                    # ① 순전파: 은닉층
    out = sig(h @ W2 + b2)                   #            출력층
    loss = np.mean((out - y) ** 2)
    d_out = (out - y) * out * (1 - out)      # ② 역전파: 출력층 오차
    d_h = (d_out @ W2.T) * h * (1 - h)       #    은닉층으로 거슬러 전달 (연쇄법칙)
    W2 -= eta * h.T @ d_out;  b2 -= eta * d_out.sum(0)
    W1 -= eta * X4.T @ d_h;   b1 -= eta * d_h.sum(0)
    if epoch in (1, 500, 2000, 5000):
        print(f"{epoch:4d}번째  손실 {loss:.4f}  출력 {np.round(out.ravel(), 2)}")
print("최종 판정:", (out.ravel() > .5).astype(int).tolist())
실행 결과
   1번째  손실 0.2514  출력 [0.48 0.46 0.47 0.45]
 500번째  손실 0.2497  출력 [0.5  0.49 0.51 0.49]
2000번째  손실 0.0013  출력 [0.04 0.97 0.96 0.03]
5000번째  손실 0.0003  출력 [0.02 0.98 0.98 0.02]
최종 판정: [0, 1, 1, 0]
조수(하루)500번째까지는 계속 0.5 언저리에서 헤매다가, 2,000번째에는 갑자기 다 맞혔어요!
박사잘 봤다! 손실이 한참 평평하다가 어느 순간 뚝 떨어지는 모습이지. 7장에서 거대 언어모델이 "갑자기" 똑똑해 보이는 이야기를 할 때 이 장면을 다시 떠올리게 될 거야.

예제 3. 손글씨 숫자: 픽셀만 주고 배우게 하기

digits_mlp.py8×8 픽셀 64개가 입력 전부
from sklearn.datasets import load_digits
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.neural_network import MLPClassifier

digits = load_digits()
Xtr, Xte, ytr, yte = train_test_split(digits.data / 16, digits.target, test_size=0.25,
                                      random_state=0, stratify=digits.target)
lr   = LogisticRegression(max_iter=3000).fit(Xtr, ytr)
mlp  = MLPClassifier(hidden_layer_sizes=(16,), max_iter=3000, random_state=0).fit(Xtr, ytr)
mlp2 = MLPClassifier(hidden_layer_sizes=(64, 32), max_iter=3000, random_state=0).fit(Xtr, ytr)
n_params = lambda m: sum(w.size for w in m.coefs_) + sum(b.size for b in m.intercepts_)
for name, m in [("로지스틱 회귀", lr), ("은닉층 16", mlp), ("은닉층 64→32", mlp2)]:
    print(name, f"{m.score(Xte, yte):.1%}")
filters = mlp.coefs_[0][:, :8].T.reshape(8, 8, 8)   # 5절 그림의 필터 8개
실행 결과
로지스틱 회귀 96.9%
은닉층 16 96.7%
은닉층 64→32 97.6%

은닉층 16개짜리 신경망의 가중치는 1,210개, 64→32 신경망은 6,570개입니다.

초파리 연구원정말 그럴까? 층 없는 로지스틱 회귀도 96.9%야. 딥러닝이 별 차이 없잖아.
박사좋은 의심이야. 8×8 숫자는 가운데 정렬된 깔끔한 그림이라 픽셀 자체가 이미 좋은 특징이거든. 차이는 배경, 조명, 각도가 제각각인 진짜 사진에서 벌어진다네. 그 증거가 다음 절의 2012년이야.

주판봇의 현장 사례와 한계

주판봇금융 이야기라면 제가 빠질 수 없죠! 딥러닝이 처음 돈을 번 곳 중 하나가 은행 수표예요. 손으로 쓴 금액을 기계가 읽었거든요!

얀 르쿤 연구팀이 만든 합성곱 신경망 LeNet은 손글씨 숫자를 읽도록 학습되었고, 이를 바탕으로 한 수표 인식 시스템은 1998년 논문 기준으로 상용 배치되어 하루 수백만 장의 수표를 읽고 있었습니다. 딥러닝 붐보다 14년 앞선 실전 사례입니다. 예제 3의 손글씨 숫자 실험이 바로 이 일의 축소판입니다.출처: LeCun, Bottou, Bengio & Haffner(1998)

강의 2강의 음성 인식 예시도 같은 흐름에 있습니다. 연속적인 소리 파형을 일정 간격으로 잘라 숫자로 바꾸고(샘플링), 그 숫자 덩어리에서 "아"와 "어"의 경계를 신경망이 스스로 찾습니다.출처: 안상선(2021), 2강 "연속 시스템과 이산 시스템", "음성 인식 시스템 설계"

한계: 잘 보지만, 왜 그렇게 봤는지 말하지 못한다

한계무슨 뜻인가
설명하기 어려움1장 규칙은 "30cm 이상이라서"라고 답할 수 있었지만, 신경망의 판단 근거는 수천~수억 개 가중치에 흩어져 있습니다. 대출 거절 사유를 설명해야 하는 금융에서 특히 큰 문제입니다.
정답 이름표가 많이 필요함ImageNet처럼 사람이 붙인 정답이 대량으로 있어야 합니다. 정답 자체가 없는 문제에는 쓰기 어렵습니다.
엉뚱한 곳에 속음판다 사진에 사람 눈에는 보이지 않는 미세한 잡음을 섞자, 신경망이 99.3% 확신으로 긴팔원숭이라고 답한 실험이 유명합니다(적대적 예제).
출처: Goodfellow, Shlens & Szegedy(2015)
주판봇99.3% 확신으로 틀렸다고요? 저랑 닮아서 땀이 나네요.
초파리 연구원그리고 하나 더. 바둑의 다음 한 수처럼 "정답"을 아무도 모르는 문제는? 이름표를 붙일 수가 없잖아.
