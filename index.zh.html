从流程图的 rule base
到工作中的 AI

本文用十五章追踪：人手写 IF-THEN 的流程图如何变成 LLM 推理模型（第1篇），以及该模型如何握住工具、自己动手工作，成为 AI 智能体（第2篇）。每章都包含公式、可直接操作的图示、实际运行过的 Python 代码和练习题。

文 · Ahn Sangsun（M-Robo 公司 CEO）

第1篇

从流程图的 rule base 到 LLM 推理模型

谁来写规则：人 → 数据 → 奖励 → 文字与人的偏好

第1篇 第1章发条机器：流程图与 rule base一台由人把每个齿轮都雕刻好装进去的机器。通电后只会沿既定路线行动，遇到设计图上没有的情况就会停下。1950至80年代的人工智能就是这样"思考"的……第1篇 第2章自己校准刻度的天平：机器学习测什么仍由人决定，但刻度该画在哪里，现在由机器看数据自己校准。这是从规则时代迈向学习时代的第一步……第1篇 第3章连看法都自己学的机器：深度学习第2章的天平需要人来决定测量什么。第3章的机器直接接收像素，连该看什么都自己找。诀窍在于第2章那一行学习……第1篇 第4章胡萝卜与鞭子的训练营：强化学习有些问题没人知道正确答案，比如围棋的下一手，或者第一次走的迷宫的出口。这时能给机器的不是答案，而是"做得好、做得不好"的分数……第1篇 第5章把词变成数字语言模型的本质简单得惊人："猜下一个词。"本章讲这个游戏的规则，以及把词变成机器能计算的数字的两种方法……第1篇 第6章一眼看尽所有词的眼睛：Transformer第5章留下了两道作业：如何记住句子开头直到末尾，以及如何让同一个"bank"在河岸与银行里得到不同的数字。2017年谷歌的……第1篇 第7章"突然"的真相：规模化2022年11月30日 ChatGPT 公开时，世界觉得 AI 突然出现了。两个月内月活用户达到1亿。但其中的零件……第1篇 第8章ChatGPT 的时刻：用人的偏好来调教GPT-3 很聪明，却不是对话对象。提问它只会接着写问题，会说得像模像样地错，还会说没人让它说的话。第4章里果蝇研究员问过的那个问题……第1篇 第9章购买思考的时间：推理模型第1章的推理引擎是把人写的规则逐条对照来得出结论。2024年的推理模型会自己长篇写出解题过程，回头检查出错的地方，并尝试多条路……
