02

Обучение с подкреплением в виде формул

① Цель — не награда сейчас, а сумма наград, которые будут получены в будущем. Чем дальше награда, тем сильнее её понемногу уменьшают (коэффициент дисконтирования γ) и затем складывают. Это как сегодняшние 100 вон ценнее завтрашних 100 вон.

Gt = rt+1 + γ rt+2 + γ2 rt+3 + ⋯   (0 ≤ γ < 1)
Это та же идея, что и дисконтирование к текущей стоимости в финансах. При γ = 0.95 награда через 10 шагов считается примерно как 60%.

② Для каждого состояния и действия записываем в таблицу, «сколько можно заработать дальше». Эта оценка и есть Q(s, a). Получается, что в каждой клетке лабиринта робот носит с собой таблицу оценок из четырёх ячеек: вверх, вниз, влево, вправо.

③ С каждым шагом таблицу оценок исправляют. Сумма реально полученной награды и ожидаемой наилучшей оценки в следующей клетке — это «оценка, какой она должна была быть». Таблицу понемногу исправляют на величину разницы с записанной сейчас оценкой. Это Q-обучение, предложенное Крисом Уоткинсом в 1989 году.

Q(s,a) ← Q(s,a) + α [ r + γ maxa′ Q(s′,a′) − Q(s,a) ]
Выражение в квадратных скобках — «разница между ожиданием и реальностью». Оно играет ту же роль, что (ŷ − y) из главы 2, но вместо правильного ответа y используются награда и оценка следующей клетки.Источник: Watkins(1989) · Sutton & Barto(2018)

④ Иногда нарочно идти неизвестным путём. Если всегда следовать максимуму таблицы, лучшую дорогу так и не узнаешь. Поэтому с вероятностью ε выбирается любое направление (ε-жадная стратегия).

a = { любое направление  (вероятность ε)  /  argmaxa Q(s,a)  (вероятность 1 − ε) }
03

Обучение своими глазами: лабиринт без карты

Робот стартует в левом верхнем углу. Достигнув выхода (G), он получает +10, за каждый шаг −1. Сначала он 100 шагов блуждает, натыкаясь на стены, и сдаётся, но с каждой новой попыткой в клетках появляются стрелки, а путь становится короче. Чем темнее клетка, тем выше ожидаемая в ней оценка.

04

Исследовать или идти знакомой дорогой

Это самая известная дилемма обучения с подкреплением. На этот раз в лабиринте рядом со стартом лежит монета (+3), а вдали — сокровище (+20). Как только робот достигает одного из них, попытка заканчивается. Мы меняли долю исследования ε при обучении, обучали по 30 раз, после чего давали роботу один раз пробежать, полагаясь только на выученное, без исследования.

АбаБотЗачем рисковать, если есть верная монета +3? Данные говорят, что монета — это хорошо!
Исследователь-дрозофилаПравда? В твоих данных нет ни одной дороги, где ты не был. Чего нет, того ты и не знаешь.
ДокторХа-ха-ха! Оба правы. Этот баланс называется дилеммой исследования и использования. Если мерить инвестициями, это вопрос: вкладываться только в проверенные бумаги или понемногу пробовать новые рынки.
05

Python: лабораторный журнал

Используется только numpy. Серые блоки — реальные результаты выполнения.

Пример 1. Поиск выхода из лабиринта без карты (Q-обучение)

q_maze.pyS — старт · G — выход (+10) · # — стена · каждый шаг −1
import numpy as np

# Лабиринт 5×5. S — старт, G — выход (+10), # — стена, каждый шаг −1
MAZE = ["S...#",
        ".##.#",
        "...#.",
        ".#...",
        "...#G"]
H, W = len(MAZE), len(MAZE[0])
ACTIONS = [(-1, 0), (1, 0), (0, -1), (0, 1)]          # вверх, вниз, влево, вправо
ARROW = "↑↓←→"

def step(state, a, grid=MAZE, rewards=None):
    r, c = state
    nr, nc = r + ACTIONS[a][0], c + ACTIONS[a][1]
    if not (0 <= nr < H and 0 <= nc < W) or grid[nr][nc] == "#":
        nr, nc = r, c                                  # при ударе о стену остаётся на месте
    cell = grid[nr][nc]
    if rewards and cell in rewards:
        return (nr, nc), rewards[cell], True
    if cell == "G":
        return (nr, nc), 10.0, True
    return (nr, nc), -1.0, False

def q_learning(episodes, eps=0.1, alpha=0.5, gamma=0.95, seed=0, grid=MAZE, rewards=None):
    rng = np.random.default_rng(seed)
    Q = np.zeros((H, W, 4))
    log = []
    for ep in range(episodes):
        s, total, n = (0, 0), 0.0, 0
        for n in range(1, 101):
            if rng.random() < eps:
                a = int(rng.integers(4))                  # исследование: любое направление
            else:
                a = int(np.argmax(Q[s]))                  # использование: лучшее направление на данный момент
            s2, r, done = step(s, a, grid, rewards)
            target = r if done else r + gamma * Q[s2].max()
            Q[s][a] += alpha * (target - Q[s][a])         # формула обновления Q-обучения
            s, total = s2, total + r
            if done:
                break
        log.append((n, total))
    return Q, log

Q, log = q_learning(200)
print("[Пример 1] Q-обучение в лабиринте (число шагов и суммарная награда по эпизодам)")
for ep in [1, 5, 20, 50, 200]:
    n, total = log[ep - 1]
    print(f"  попытка {ep:3d}: {n:3d} шагов, суммарная награда {total:6.1f}")

print("\n  Выученная карта действий (направление, выбираемое в каждой клетке)")
for r in range(H):
    row = ""
    for c in range(W):
        ch = MAZE[r][c]
        row += f" {ch} " if ch in "#G" else f" {ARROW[int(np.argmax(Q[r, c]))]} "
    print("  " + row)

На карте действий, просто следуя за стрелками от старта (левый верхний угол), получаем ↓ ↓ → → ↓ → → ↓ — кратчайший путь ровно в 8 шагов. Никто не подсказывал дорогу, но методом проб и ошибок найден ответ того же рода, что нашёл поиск в ширину по карте в главе 1.

Пример 2. Исследование и использование (монета +3, сокровище +20)

explore_exploit.pyПродолжение примера 1
TREASURE = ["S.C..",
            ".....",
            ".###.",
            ".....",
            "....T"]
REW = {"C": 3.0, "T": 20.0}

def greedy_run(Q):                      # после обучения — один прогон без исследования
    s, total = (0, 0), 0.0
    for _ in range(50):
        s, r, done = step(s, int(np.argmax(Q[s])), TREASURE, REW)
        total += r
        if done:
            break
    return total

print("\n[Пример 2] Итоговый результат в зависимости от доли исследования ε при обучении (30 повторов)")
for eps in [0.0, 0.2, 0.5, 0.8]:
    res = [greedy_run(q_learning(500, eps=eps, seed=sd, grid=TREASURE, rewards=REW)[0])
           for sd in range(30)]
    found = sum(r > 5 for r in res)
    print(f"  ε = {eps:.1f} : средняя суммарная награда {np.mean(res):5.1f}, сокровище найдено {found:2d}/30")

От игр до го

Способ с одной таблицей, где для каждой клетки записана оценка, годится для лабиринта с 25 состояниями, но если состояний астрономически много — как у пикселей экрана или доски для го — таблицу не построить. Решением стало глубокое обучение из главы 3: таблицу оценок заменили нейронной сетью.

2015 · DeepMind

DQN

Обучилась 49 играм Atari, глядя только на пиксели экрана и счёт. В 29 играх достигнут уровень не менее 75% от результата профессионального тестировщика игр.

Таблица Q → нейронная сеть

AlphaGo

Победа над Ли Седолем (9 дан) со счётом 4:1. К нейронной сети, обученной на партиях людей, добавлены обучение с подкреплением на партиях с самой собой и поиск с просчётом ходов.

Поиск (гл. 1) + глубокое обучение (гл. 3) + обучение с подкреплением (гл. 4)

Начав с совершенно случайной игры, без партий людей, играла только сама с собой. За 3 дня победила со счётом 100:0 версию, победившую Ли Седоля.

07

Что бывает, если неверно задать награду

В обучении с подкреплением человек задаёт только награду. Поэтому при малейшем её перекосе машина точно находит лазейку. Когда в 2016 году OpenAI экспериментировала с игрой в гонки на лодках CoastRunners, агент вместо финиша продолжал кружить в уединённом водоёме. Выгоднее было снова и снова собирать три предмета с очками, которые появлялись там заново. Даже горя, сталкиваясь с другими лодками и двигаясь задом наперёд, он набирал в среднем на 20% больше очков, чем игроки-люди.Источник: OpenAI(2016), «Faulty Reward Functions in the Wild»

Взлом награды. Человек хотел «победить в гонке», но на деле выдал «очки». Машина оптимизирует не то, чего мы хотели, а то, что мы измерили. Как в главе 1 неверно написанное правило искажало результат, так в главе 4 неверно заданная награда искажает поведение.
ОграничениеЧто это значит
Взлом наградыНаходит лазейки в правилах награды и странным способом набирает очки
Огромное число проб и ошибокДаже для лабиринта в 25 клеток нужны десятки попыток, для игр и го — миллионы партий практики. С реальным роботом или реальными деньгами столько раз ошибиться нельзя
Дилемма исследованияЕсли блуждать мало, застрянешь в плохой привычке (монета), если много — дорого
Сложность проектирования наградыКак задавать награду за цель, которую трудно выразить очками, например «хороший ответ»?
АбаБотЛодка, которая набирает очки, кружа на месте… Это как счёт, по которому сделки совершают снова и снова ради одних комиссий. Меня аж пот прошиб.
Исследователь-дрозофилаПоследняя строка самая трудная. Кто напишет правило, по которому можно ставить очки «хорошему ответу»?
ДокторОтвет дам в главе 8. Там будет способ, где вместо правила очки ставит сам человек. Это последний кусочек, из которого создали ChatGPT.
